# UI-автотесты сервиса «Доска»

## Описание проекта

Проект содержит UI-автотесты учебного сервиса «Доска», написанные на Python с использованием pytest и Selenium WebDriver. Тесты проверяют регистрацию, вход и выход пользователя, а также создание объявления. Локаторы вынесены в отдельный модуль `locators.py`.

## Установка проекта

1. Установите Python 3 и Google Chrome.
2. Склонируйте репозиторий и перейдите в папку проекта.
3. Создайте виртуальное окружение и активируйте его:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   В Windows активируйте окружение командой:

   ```powershell
   .venv\Scripts\activate
   ```

4. Установите зависимости:

   ```bash
   python -m pip install pytest selenium
   ```

## Запуск проекта

Запустите тесты из корневой папки проекта:

```bash
python -m pytest tests -v
```

Для тестов входа, выхода и создания объявления необходима заранее зарегистрированная учётная запись. Её можно передать через переменные окружения `DESK_TEST_EMAIL` и `DESK_TEST_PASSWORD`. Если они не заданы, проект использует значения тестовой учётной записи из `locators.py`.
